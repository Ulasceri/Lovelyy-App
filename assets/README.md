# Shared assets

Source files shared across platforms (Android now, iOS later).

- `fonts/`: Quicksand (SIL Open Font License, see `Quicksand-OFL.txt`). The Android app uses static
  weights generated from the variable font, in `android/app/src/main/res/font/`.
- `animations/`: Lottie / Rive files for the cat (step 2).
- `images/`: app icon sources, illustrations.
